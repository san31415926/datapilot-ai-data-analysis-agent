# DataPilot 样例数据

`sample_ecommerce.csv` 和 `sample_ecommerce.xlsx` 是通过固定随机种子生成的合成中文电商订单数据，不包含真实用户、企业或交易信息。

## 字段说明

| 字段 | 含义 |
| --- | --- |
| 订单编号 | 合成订单唯一标识；样例中保留一条重复订单用于质量检查 |
| 订单日期 | 2025 年上半年的订单日期 |
| 地区 | 华东、华南、华北、西南、华中或西北 |
| 渠道 | 直营网店、电商平台、直播间或企业团购 |
| 商品类别 | 厨房用品、数码配件、家居日用或食品饮料 |
| 商品名称 | 合成商品名称 |
| 数量 | 订单商品数量 |
| 单价 | 单件商品价格，单位为元 |
| 折扣 | 订单折扣系数，例如 `0.9` 表示九折 |
| 销售额 | 订单成交金额，单位为元 |
| 成本 | 合成商品成本，单位为元 |
| 客户类型 | 新客、老客或会员 |
| 订单状态 | 已完成、退款中或已取消 |

## 质量检查场景

- 总计 243 行：240 条随机基础订单、1 条大额企业团购订单、1 条异常金额订单和 1 条重复行。
- `渠道` 和 `客户类型` 各包含一个缺失值。
- `ORD-2025-HIGH` 是金额计算正常的大额订单，用于测试分组统计和重点订单展示。
- `ORD-2025-ANOMALY` 的销售额被设为 `99999.99`，与数量、单价和折扣明显不匹配，用于测试异常检测。

## 重新生成

在项目目录执行：

```powershell
.\.venv\Scripts\python.exe scripts\generate_sample_data.py
```

生成逻辑位于 `src/sample_data.py`，默认种子为 `20250730`。重新生成不会访问网络，也不会覆盖项目外的文件。
